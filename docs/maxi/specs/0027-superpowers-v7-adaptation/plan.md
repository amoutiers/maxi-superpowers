# Superpowers v7 Adaptation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use the installed Maxi implementation owner and x-develop adapter to execute this plan through bundled superpowers:subagent-driven-development. Preserve each task's interfaces and assertions.

**Goal:** Adopt exact Superpowers v7.0.0 with governed design intake, working host adapters and installed qualification.
**Architecture:** Keep upstream skills byte-identical and adapt existing Maxi owners at their handoff boundaries. Reuse root host adapters, release inventories and integration evidence checkers.
**Tech Stack:** Existing Bash, Python standard library, Node.js, jq, Git and authenticated Codex CLI.
**Spec:** [0027-superpowers-v7-adaptation/spec](spec.md).

## Summary

Import upstream v7.0.0, then integrate its new brainstorming and builder check without changing the product pipeline. Repair root hook and Hermes behavior, add native Antigravity packaging, and extend existing qualification rather than introducing another executor.

## Technical Context

**Language/Version**: Existing portable Bash, Python and JavaScript conventions.
**Primary Dependencies**: Existing tooling only; no new runtime dependency.
**Storage**: Existing Markdown artifacts and SDD evidence.
**Testing**: Fast-tier shell/Python checks and installed Codex integration.
**Target Platform**: Existing sixteen-host inventory; native qualification limited to hosts actually exercised.
**Project Type**: Agent skills and host plugin adapters.
**Performance Goals**: No new per-model-call hook process for Antigravity.
**Constraints**: Exact vendoring, installed-owner binding and preserved evidence contracts.
**Scale/Scope**: 15 upstream skills, 19 Maxi-native skills and ten FSM states.

## Global Constraints

- Import exact Superpowers v7.0.0 through the existing subtree bump/sync scripts; preserve byte-identical vendoring.
- Preserve 19 native skills, 15 upstream skills, ten FSM states, three fixed product review boundaries, artifact ownership and the SDD completion contract.
- Bind delegated skills and helpers to the owning installed snapshot without a co-installed-engine or client-repository fallback.
- Retain canonical artifacts, settled choices, requested destinations and owner-only returns.
- Update the Mandatory Sync five with each owning pipeline change; preserve historical artifacts.
- Use existing tooling without new runtime dependencies; write new artifacts and changed technical documentation in English.
- Preserve user configuration and unrelated work. Publication and branch integration require their own explicit authorization.
- Record deterministic checks, native validators and actual installed-agent behavior as separate evidence.

## Review Focus

- Task 1, installed v7-builder and v7-skip cases: a complete or interview-opt-out request still reaches author, one builder check and actual clarification without execution.
- Task 2, empty-PATH hook tests: syntactically valid JSON must contain the complete session skill rather than an error string.
- Task 3, Antigravity bootstrap tests: a surfaced description must lead to the project check while a non-Maxi conversation does not activate the pipeline.
- Task 4, evidence-checker regressions: an unrelated child or echoed prompt must not acquit the builder-check requirement or disappear from allocation accounting.
